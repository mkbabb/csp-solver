# Bundled font licenses

Three self-hosted woff2 subsets ship here, 22,572 B total. All three are licensed under
the SIL Open Font License, Version 1.1. Each subset is a Modified Version under the OFL
(it carries a reduced glyph set), redistributed under the same license per clause 5. None
of the three declares a Reserved Font Name, so the subset keeps the upstream family name.

| Family       | Subset file                | Bytes  | Copyright                     | License text                                   |
| ------------ | -------------------------- | ------ | ----------------------------- | ---------------------------------------------- |
| Patrick Hand | `patrickhand-subset.woff2` | 4,312  | Patrick Wagesreiter           | [`OFL-PatrickHand.txt`](./OFL-PatrickHand.txt) |
| Fraunces     | `fraunces-subset.woff2`    | 14,636 | The Fraunces Project Authors  | [`OFL-Fraunces.txt`](./OFL-Fraunces.txt)       |
| Fira Code    | `firacode-subset.woff2`    | 3,624  | The Fira Code Project Authors | [`OFL-FiraCode.txt`](./OFL-FiraCode.txt)       |

Each `OFL-*.txt` is the upstream license verbatim, its copyright line intact. The full OFL
1.1 terms and FAQ are at <https://openfontlicense.org>.
