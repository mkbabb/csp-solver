# games/sudoku

The default game: N=2,3,4 grids (4×4 through 16×16), with
`EASY`/`MEDIUM`/`HARD` difficulty. N=2 and N=3-easy/medium live-generate in the
Worker; N=3-hard and N=4 come from the embedded bank. Own Worker solve path (`solver.worker.ts` +
`useSolver`, `size` on the wire), own control panel. Templates in
`data/templates.ts` are AUTO-GENERATED by `vite.config.ts` from
`csp-solver/data/sudoku_puzzles/` — never hand-edit. Board is an ARIA `role="grid"`
with roving tabindex; given cells carry the `sparkle-rainbow` stroke, user cells
`user-ink`. Never imports `games/futoshiki/**` (ESLint-enforced); reaches into
`pencil/` freely.
