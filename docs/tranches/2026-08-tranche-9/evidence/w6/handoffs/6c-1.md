# 6c-1 — `spoken-controls.spec.ts` carries an UNDECLARED per-row engine skip

**Land this in the same commit that adds W3's specs to `SPEC_MANIFEST`, or check 4 reds.**

Out of lane 6C's fence twice over: `e2e/spoken-controls.spec.ts` is W3's file, and adding a spec
name to `SPEC_MANIFEST` is the chair's fold. But the two halves are one act now, and this note
carries the half that is easy to miss.

## What changed under it

T9-W6 §6.3 gave `check-pw-projects.mjs` check 4 a SECOND grain. It no longer only asks whether a
FILE runs in both engines (Playwright's resolution answers that); it now reads each manifest
spec's own source and reds on any `test.skip(browserName === '<engine>')` that `HOLDOUTS` does
not declare. That clause is the anti-growth law: without it, moving `share-truth` from a
file-scope `testIgnore` to a row-scope skip would have traded a WATCHED narrowing for an
unwatched one, which is CH-56 re-opening one grain down.

The clause is scoped to `SPEC_MANIFEST` on purpose — a spec that has not joined the closed set
yet is check 6's business, not check 4's. So today `spoken-controls.spec.ts` is invisible to it.
The moment it joins the manifest, it is visible, and it carries exactly one such skip.

## The seam

`e2e/spoken-controls.spec.ts:243` — W3 §3.6's row:

```
    test.skip(
      browserName === 'webkit',
      'PW-WebKit has no clipboard-write permission (playwright.config.ts records the same gap for share-truth.spec.ts)',
    );
```

Its enclosing title, which is the key the record uses:

```
the outcome is spoken, and the name agrees with the label at every beat
```

## The literal to land

In `web/frontend/scripts/check-pw-projects.mjs`, inside `HOLDOUTS`, add this entry beside
`share-truth.spec.ts` (it is the same gap, on the same API, in a second file):

```js
  "spoken-controls.spec.ts": {
    // The FILE runs in both engines; ONE row needs a clipboard grant PW-WebKit cannot give.
    engines: ENGINES,
    rows: [
      {
        title: "the outcome is spoken, and the name agrees with the label at every beat",
        engines: ["chromium"],
        why:
          "PW-WebKit has no clipboard-write permission — `browserContext.grantPermissions: " +
          "Unknown permission: clipboard-write` (re-measured at @playwright/test 1.61.1). The " +
          "row grants clipboard-read/write to press Share for real; the same gap share-truth's " +
          "success row carries, in a second file. The skip and its reason ride the row at " +
          "spoken-controls.spec.ts:243.",
      },
    ],
    why:
      "PER-ROW, not per-file (T9-W6 §6.3). Only the §3.6 copy-outcome row needs the grant; " +
      "every other row in the file asserts live regions that both engines publish.",
  },
```

`ENGINES` is already in scope at that point in the file.

## Why it cannot just be left off

`liveTests` subtracts declared row holdouts from the engine they are held out of, so the entry
is not decoration — it is what keeps `playwright.config.ts::webkit`'s floor a floor on rows that
actually ASSERT. Leaving the entry off does not merely trip check 4; it also leaves the webkit
floor counting a row that lists and asserts nothing, which is precisely the accounting the
QUARANTINES table was built to stop.

## Not in scope here

`follow-still-authorship.spec.ts` and `spoken-gallery.spec.ts` (the other two manifest reds)
carry NO engine skips — verified by the same reader this gate uses. They need their names in
`SPEC_MANIFEST` and nothing else.
