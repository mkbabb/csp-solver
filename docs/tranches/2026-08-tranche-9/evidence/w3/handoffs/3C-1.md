## B. `e2e/mobile-affordances.spec.ts` — two rows, both engines

Both rows open the dock sheet and then TAP A BOARD CELL AND TYPE INTO IT. With the sheet up the
board is painted over (59–62/81 cells at 390×844, measured both engines), so that gesture is one
a reader cannot make: the finger lands on the sheet. The rows only ever passed because the
covered board was still live, which is the P0 §3.1 cures.

The board is dirtied for a REASON in both — to arm the two-tap — so the cure is to dirty it with
the sheet SHUT and re-open, which is also the only order a reader can perform.

**`e2e/mobile-affordances.spec.ts:393`** — replace

  await dirtyInput.tap();

  // That is the order a reader has to use, so it is the order the row uses.
  await closeDrawer(page);
  const blank = await firstBlank(page, ".sudoku-cell");
  const dirtyInput = cellInput(page, blank);
  await dirtyInput.tap();
```

and re-open before the Clear tap that follows: insert, immediately after
`await expect(dirtyInput).toHaveValue("5");` (`:396`),

```
  await openDrawer(page);

**`e2e/mobile-affordances.spec.ts:443`** — the same shape. Replace
