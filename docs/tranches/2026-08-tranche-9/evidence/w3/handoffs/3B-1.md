## The seam

`web/frontend/src/games/shared/GameBoard.vue:489-495`


## Two candidate cures, both one line

**A — narrow the truth at its single source (preferred).** `BoardHost.vue:88` already holds the
per-cell solved map the cells are bound from (`model.solvedValues.value`, :281). Narrowing
`cellAuthors` there fixes the tape AND `authorNameAt` from one place:

`web/frontend/src/games/shared/BoardHost.vue:88` — replace

```ts
const cellAuthors = computed(() => props.model.cellAuthors.value);
```

with

```ts
// A hand is only claimable on a digit that hand actually wrote. A revealed cell is the
// SOLVER's (it wears `#solver-ink`), a printed clue is nobody's, and an erased cell has no
// digit to own — the ledger stamps all three, so the claim is narrowed here, once, for both
// consumers: the tape (GameBoard) and the cell's own name (`authorNameAt`).
const cellAuthors = computed(() => {
  const out: Record<string, { slug: string; self: boolean }> = {};
  for (const [pos, a] of Object.entries(props.model.cellAuthors.value)) {
    if (pos in props.model.solvedValues.value) continue;
    if (props.model.givenCells.value.has(pos)) continue;
    if ((props.model.values.value[pos] ?? 0) === 0) continue;
    out[pos] = a;
  }
  return out;
});
```

The name's kind-branch in `useGameCell` stays either way — it is the cell's own truth and does
not depend on who narrows the map upstream.

**B — gate the tape alone.** Add the solved test inside `hoveredAuthor`; needs GameBoard to
receive a per-cell solved set it does not have today (its props carry `cellAuthors` and no
`solvedValues`), so it costs a new prop for one consumer. A is cheaper and closes both.
