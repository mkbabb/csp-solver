## The shape: a query flag arming a same-origin chunk

`public/_headers` serves `script-src 'self' 'wasm-unsafe-eval'`, no `'unsafe-inline'`—a
`javascript:` bookmarklet is refused by the estate's own CSP. So: `?__probe=1` →
one `import()` of `probe/devicePaint.ts` behind `new URLSearchParams(location.search).has('__probe')`,
emitted content-hashed under `/assets/`, `'self'`, no header change. It's `perf-rig/probe.js`'s
`?__run=` grammar moved into the bundle, because the edge has no `probe-server.mjs`. Inert by
default; nothing else on the boot path; no rendered pixel changes (π untouched).

## Cold, warm, taint

The page can't clear its own cache. A two-button first screen: run 1 = a Private tab on a
device that hasn't loaded the edge today (cold); run 2 = reload (warm). Undeclared banks as
`cache: undeclared`. `visibilitychange` / `blur` / `pagehide` → `taint[]`, the readout goes red
and the number isn't quoted. A lone 1,000–1,300 ms rAF delta is occlusion (WebKit suspends rAF)
and taints. Low Power Mode is invisible to the page: a checkbox, banked as an owner assertion.

## Export: one tap

**`navigator.clipboard.writeText(json)`** from the tap's own gesture—HTTPS, already shipped on
this origin (`useGameState.ts:1011`), deliberately not denied in `Permissions-Policy`. Under it,
the same JSON in a `<pre>` with `user-select: text`, because `writeText` fails silently when an
`await` loses the gesture. `navigator.share` is REFUSED as designed (`web-share=()` disables it
for every origin including self; enabling it is a security-file change that buys nothing).
`<a download>` on `blob:` is a third button and relied on for nothing. One JSON line per
reading, `readiness.jsonl`'s shape, so `A6/summarize-readiness.mjs` folds device and proxy rows
into one table.
