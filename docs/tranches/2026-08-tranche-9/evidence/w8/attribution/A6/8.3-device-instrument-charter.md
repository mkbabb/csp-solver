## 1. Why a bookmarklet is REFUSED, and a query flag is the only shape

`web/frontend/public/_headers` serves, on every path of the deployed edge:

```
script-src 'self' 'wasm-unsafe-eval'
```

There is **no `'unsafe-inline'` in `script-src`**. Under CSP Level 3 a `javascript:` URL is a
script source governed by `script-src` and is blocked unless `'unsafe-inline'` is present, so a
bookmarklet typed into Safari's address bar on `sudoku.babb.dev` is refused by the policy the
estate deliberately narrowed. Web Inspector injection is exempt from CSP, but it needs a Mac
cabled to the phone — that is a rig, not the E8/CH-35 ten-minute shape the wave asked for.

**The shape that survives: a query flag that arms a same-origin chunk already in the bundle.**
`?__probe=1` → the app `import()`s `probe/devicePaint.ts`, Vite emits it content-hashed under
`/assets/`, it is `'self'`, and CSP is satisfied with no header change. This is exactly
`perf-rig/probe.js`'s own grammar (`?__run=<runId>` arms the probe; without it the page is a
plain app — probe.js:8) moved from a serve-time injection into the bundle, because the
deployed edge has no `probe-server.mjs` to inject it.

**The flag must be inert by default and dead weight only when set.** One dynamic `import()`
behind `new URLSearchParams(location.search).has('__probe')`, nothing else on the boot path.

## 2. What it reads

Every mark is the same mark this lane read at chromium/webkit, so the device number and the
proxy number are the same quantity. The definitions are load-bearing:

| mark | how it is taken | why this tell |
| --- | --- | --- |
| `firstPaintMs` | `PerformanceObserver` `paint` | **Safari ships no `first-paint` entry** — only `first-contentful-paint`. Prints `NOT MEASURED`, never 0. Confirmed here: every webkit row in `readiness-table.md` has `firstPaint NOT MEASURED` and an `fcp`. |
| `fcpMs` | `paint` → `first-contentful-paint` | present in Safari |
| `lcpMs` | `largest-contentful-paint`, buffered | **Safari 26 does ship LCP.** Verify on the owner's device before trusting the row; if absent, print NOT MEASURED. |
| `boardReadyMs` | the ONE W8 definition: `.board-group` VISIBLE (it is `v-show`n and both control-panel twins are always mounted, so presence is not enough) + the first `.cell`-class element's `getBoundingClientRect()` non-zero + one rAF after that | the wave's single readiness mark |
| `firstBakeMs` / `bakeLayers` | `MutationObserver` on `childList`/`subtree`: the first `.boil-frame-bitmap` in the DOM | the raster bake landed (`HandDrawnGrid.vue:386`) |
| `boardDrawnMs` (= first boil tick) | `MutationObserver` on `class` attributes: the first `is-active` MOVE between `.boil-frame-bitmap`/`.boil-frame` siblings after board-ready | the board is ready AND drawn AND boiling — the proposed budget metric |
| `firstToggleBlockingMs` | the owner taps the dark-mode toggle once; rAF gaps over 50 ms summed across the 1800 ms after the tap | the re-bake this lane measured at 429 ms (mobile/4×, chromium). **`longtask` does not exist in WebKit** — the rAF-gap census is the only proxy, and it is labelled a PROXY on the readout |
| `secondToggleBlockingMs` | the same, on the second tap | the first/second delta IS the pre-warm argument |
| `drawerFlipMs` | tap `.drawer-tab`, `MutationObserver` on `aria-expanded`, then 2 rAF | M02's flip latency |
| `rafGapProxyTbtMs` | Σ max(0, gap − 50) over gaps in the first 3000 ms | the TBT stand-in on an engine with no `longtask`. **Never called TBT on the readout.** |
| `transferBytes` / `resourceCount` | `performance.getEntriesByType('resource')` | the transport half of the cold/warm delta |

**Cold vs warm.** The instrument cannot clear its own HTTP cache. The owner's script says:
run 1 = a Private tab on a device that has never loaded the edge today (cold), run 2 =
reload in the same tab (warm). The readout stamps which the owner declared, from a two-button
first screen, and a reading with no declaration is banked as `cache: undeclared`.

## 3. Taint

- `visibilitychange`, `blur`, `pagehide` → push the event and its `performance.now()` into
  `taint[]`; a non-empty `taint[]` colours the readout red and the number is not quoted.
- **Occlusion suspends rAF outright in WebKit** (`perf-rig/README.md`, "Traps"): the tell is a
  lone 1000–1300 ms delta. The instrument watches for it explicitly and taints on it, because a
  phone that locked its screen mid-reading otherwise reports a spectacular TBT proxy.
- Low Power Mode and thermal state are invisible to the page. The readout carries a
  self-declared checkbox — "Low Power Mode off?" — banked as an owner assertion, never a
  measurement.

## 4. Export — ONE tap, and what actually works on iOS Safari

Three candidates, one survives cleanly:

| mechanism | verdict on the deployed edge |
| --- | --- |
| `navigator.share(<JSON blob/file>)` | **REFUSED as designed.** `public/_headers` sets `Permissions-Policy: … web-share=() …` — an empty allowlist disables Web Share for **all origins including self**. `navigator.share()` rejects. It could be enabled by moving that token to `web-share=(self)`, but that is a header change in a security file, and it buys nothing clipboard does not. Named here so 8.3 does not rediscover it live. |
| `<a download>` on a `data:`/`blob:` URL | **NOT RELIED ON.** iOS Safari's handling of the `download` attribute on `blob:`/`data:` has been partial across versions; a `data:` navigation opens a viewer rather than saving. Offered as a third button, never as the path. |
| **`navigator.clipboard.writeText(json)`** | **THE PATH.** Secure context (the edge is HTTPS), fires from the tap's own gesture, and the estate already ships it on this origin: `src/games/shared/useGameState.ts:1011` writes the permalink with it, and `_headers`' own comment records that `clipboard` is deliberately NOT denied in `Permissions-Policy` for exactly that affordance. The owner taps COPY, then pastes into any note or message. |

**Belt and braces, and it costs nothing**: the readout also renders the JSON into a
`<pre>` with `user-select: text` under the button. If `writeText` throws (it does, silently,
when the gesture is lost to an `await`), select-all still works. The JSON is one line per
reading, the same shape as `readiness.jsonl` here, so `summarize-readiness.mjs` folds the
device rows and the proxy rows into one table without a second reader.

## 5. Compliance

- **CSP**: `'self'` chunk, no inline script, no header change. Verified against the exact
  policy text in `public/_headers`.
- **M19**: the owner runs it. No `osascript`, no `open -a Safari`, no `run-safari.sh`,
  `run-sim.sh`, `cpu-attrib.sh` or `matrix.sh` — all four take the machine over.
- **O-12**: a LOCAL/device instrument. It never enters CI; CI is sixteen browserless lanes.
- **M09 (the quality law)**: the instrument READS. It drops no bake, thins no boil, removes no
  filter. `?__probe` changes no rendered pixel, so π identity is untouched by its landing.
- **Evidence policy**: text-first, JSON lines, banked under `evidence/w8/`.
