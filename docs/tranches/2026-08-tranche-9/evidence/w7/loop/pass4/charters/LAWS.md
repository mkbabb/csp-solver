  beside it. Seven trees returned with an estate row RED and undeclared. A red you inherit is

- THE @PROPERTY LAW (four clauses, pass 3) plus **P4 ·** exactly ONE block per home (§13's rungs at
  file scope in the first static stylesheet; §10's lengths beside them), never nested inside a rule
  (`@property` inside `:root{}` is illegal; the bundler hoists it silently — a brace-nested
  registration is RED), and an `initial-value` equal to the fallback you struck IS the fallback
  (`--toggle-bleed: 0px`). With `inherits: true` an invalid value falls back to the INHERITED value,
  not the initial — a discriminator asserts against the ancestor stated. Consumers write `var(--x)`
  bare; a class and its inline publisher bound by one predicate make a `var(x, fallback)`
  unreachable — test the PREDICATE.
- **P4 · An escape row in any ledger carries its VALUE** (a MOVED row names `newKey` and reds
  unless that key exists at ≥ the banked value; a RETUNE row names `to: <ms>`; an ADMITTED row
  reds STALE when the site obeys the rule). A row naming a cite and no number disarms the gate
  permanently — third occurrence in the campaign; an invariant. Key a negative control on the
  RULE's shape, never on one site's literal text.
- **P4 · A painted-contrast row samples the ground the stroke ABUTS** and carries the
  threshold-sensitivity row (worst column at 50/70/90/100 % of median ink mass + the fraction of
  columns under the floor); `ringOnFace`/`ringOnCard` from one composite is ONE row. A painted ring
  reading without the core DISTRIBUTION (max / p30 / median / fraction < 3.0, every arm, ring-OFF
  subtracted) is a best-pixel ceiling. Read a computed style AFTER the estate's own transition
  settles (poll to a stable value; never a fixed 200 ms).
- **P4 · An indicator gate reads `outlineStyle`, never `outline-width`** (`outline: none` leaves the
  width at `medium` = 3px), AWAITS A FLUSH before reading a Vue-rendered ring, and runs a STRANDED
  negative control (an injected focusable with no indicator) in the same walk.
- **P4 · A RECT IS NOT PAINT.** A "shown" claim is `elementFromPoint` at the subject's own centre +
  a byte read of its box + the clipping-ancestor walk. `page.screenshot({ animations: 'disabled' })`
  fast-forwards a fold and moves the subject out from under its clip.
- **P4 · Any receiver-side per-key timer map needs a TWO-MOVERS row**; a `deep: true` watch re-fires
  on every getter re-run. **A close is a pose**: `v-if="open && …"` inside a transitioned sheet cuts
