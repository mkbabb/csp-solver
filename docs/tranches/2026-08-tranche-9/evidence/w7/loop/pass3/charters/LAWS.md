## Gates
- Every gate runs BARE, exit code unpiped. A born-RED row is demonstrated on THIS tree with its
  negative control in the same run; a gate a critic proved cannot fail is re-cut before it counts.
  Every e2e/unit re-aim is RUN, not written. The dist is BUILT in the worktree (own cacheDir) and
  SERVED for the filter census and the goldens (a golden move is a STOP, chair §6.4).
- THE @PROPERTY LAW (chair §6.5, four clauses learned in pass 3): the registration lives in the
  first STATIC stylesheet, never emitted by the publisher it guards; `inherits: true` unless the
  consumer is the declaring element; the `initial-value` is computationally independent AND fails
  VISIBLY (a 12px initial re-creates the fallback it struck); the born-RED ablation runs on a host
  that DECLARES the token, not one that declares nothing. Consumers write `var(--x)` bare; every
  `, 0px` / `var(--x, fallback)` on a measured token is struck. `--ring-ink` is MRK-LIVE's one
  declaration: copy that line (cited) and consume it bare.
- Budgets are RATES per second, never counts per frame or per event (a 120 Hz panel doubles a
  frame count). `getAnimations()` on the target's ancestor path, never document-wide.
- A painted-contrast gate carries the threshold-sensitivity row (worst column at 50/70/90/100 %
  of median ink mass + fraction of columns under the floor). `check-ink-pressure` prices a
  composite at full coverage; a thin stroke is un-gated until a painted row exists.
- A regime is keyed on the space the surface has, never on a viewport-height media query alone
  (`(min-height: 800px)` fires on a 1280×720 laptop). A roster watch diffs the ID SET, never the
  count. A `:key` bound to the string that changes re-mounts the node on every write.
- Every var() in a timing (or any) slot must resolve against the declared/registered set — the
  undefined-token census (MOT-VERB owns it; every lane consuming a rung runs the copy).
