`reaches()` asks whether a new subject carries every class of the banked subject. `.game-cell` does not

RESOLVED TO TEMPLATE ELEMENTS" in the library's read set (TAPE's element keying is in the ONE copy). The
gate does not wire it, so this is also a SHAPE-law row: the library reads the shape and the gate does not
use it. **The fix:** key the ratchet on the TEMPLATE ELEMENTS a banked subject's classes land on
(DigitCell's static `game-cell` plus its bound `cell-reveal-animated`). Any new duration site whose
subject reaches one of those elements, below the banked length, reds. K7r and K7s are the plants, and
L7b/L7e (scoped, which don't reach) stay as the over-red check.

enclosing call argument or initializer (the expression between the consumer's delimiters) against the
rungs it reads. An expression that can return a shorter read, or that is anything but a bare read or a
