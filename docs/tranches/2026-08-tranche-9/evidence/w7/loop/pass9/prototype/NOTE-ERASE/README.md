## 4 · Row 4 — user-origin and UA-origin `!important`: DECLARED UNPLANTABLE this pass, per engine, with the mechanism

- **What they would do.** The hook's writes are AUTHOR-origin inline `!important`. A USER-origin `!important` (and a UA one) outranks them in the cascade, so Vue's clock reads the user's `animation-duration`/`delay` and the hook's value is lost. When the user's duration matches a verb that runs, the clock is still honest (it waits for what runs). The hole is a user `animation-name: none !important` or a name with no `@keyframes` together with a user duration: nothing runs, and Vue waits the user's length.
- **Chromium.** Playwright has no user-stylesheet API. CDP's inspector stylesheet (`CSS.createStyleSheet` / `addRule`) cascades as an author sheet, so it can't plant the origin. The one route that can is an extension's `chrome.scripting.insertCSS({origin: "USER"})`. It needs a persistent context with `--load-extension` on the full Chromium channel (the headless shell loads no extensions). I did NOT build it this pass.
- **WebKit.** Playwright's WebKit exposes no user stylesheet. `WKUserContentController` user sheets exist in the WebKit API, but Playwright doesn't surface them. Unplantable from this rig.
- **UA origin.** No engine lets automation inject into the UA sheet. Unplantable in both engines.
- **The explicit `done` on `@leave`, priced and NOT built** (named for the owner). A two-parameter hook, `(el, done) => Promise.all(el.getAnimations().map((a) => a.finished)).then(done, done)`, takes the clock from Vue. The node then drops when what RUNS finishes, whatever any origin writes, so user and UA `!important` stop mattering. Costs:
  1. Vue's timeout fallback goes. A cancelled animation rejects `finished` (`AbortError`), so every path must still call `done`, or the node never drops.
  2. The one-parameter law is a gate today: G16's static half asserts `function stopTheClock(el: Element): void`, and the drop-clock rows rest on Vue's own reading. Both would be re-cut.
  3. The rung write becomes moot on the leave, so `--motion-whisper`'s leave reader goes. The ladder's consumer row (lint:theme-tokens readers) would need a fold entry.
  4. `finished` resolves in the same animation-frame update that dispatches `animationend`, so a running verb costs nothing in frames. A still leave would drop on the next microtask instead of on Vue's `nextFrame` (≈ one frame sooner).

  Not built. It is a contract change that moves Vue's clock and two gates, and nothing on this site plants the origin that needs it.
