## 3. FINDINGS THE PROTOTYPE PRODUCED (not in the spec)

**F-1 · The die renders 17.97px today, not 28px — the brief's rank arithmetic is wrong in F2's
favour.** Inside the column-flex `.deal-btn`, the `<svg>` is a main-axis flex item and shrinks:
measured 17.97px desktop / 19.84px mobile on the shipped dist. Real ratio vs the 25.9px difficulty
heading is **0.694:1**, not the 1.08:1 the brief states — the commit verb is *two-thirds* the
height of a heading it commits. **D2 therefore needs one extra declaration** — without
`.deal-btn > svg { flex: 0 0 auto }` a `:size="56"` still renders ~18px and the whole rank claim
evaporates. Reproducible in the mock: `?v=base` deliberately omits the fix.

**F-2 · The Candidates chip reads as a fourth pen zone.** In the desktop well the row is
`away · desk · clipped · hidden` — four objects, four hand-script captions, one row. The grouping
the design intends (three-place radiogroup + one unrelated switch) is not the grouping the eye
gets. The *mobile* stacking (chip on its own row beneath the pen scene) reads correctly.
**Recommendation: adopt the mobile stacking at every width** — the desktop has 239px of headroom
and the change costs the ~48px the stacked chip adds. See `out/f2-desktop-light.png` vs
`out/f2-mobile-light.png`.

**F-3 · `PencilObject`'s lift is a transitioned transform ON a filtered element.** Census
(`out/idle-paints.json` → `transitionedTransformOnFilteredElement`) flags 3 nodes in both engines.
Chromium composites it; **WebKit paints SVG filters unlayered**, so the 150ms lift re-rasters
`grain-static` per frame — the same mechanism as the ledgered BoilDivider defect, at ~1/300th the
area and one-shot per tap rather than per beat. Not a steady-state regression (idle paints are 0),
but the honest fix is 3 lines: move the `transition`/`transform` to a wrapper element so the
filtered `<svg>` is a *descendant* of the animated box, not the animated box.

**F-4 · The plumbing inventory undercounts.** The spec books "+5 one-line bindings ×5 games."
Sudoku and Futoshiki mount thin `ControlPanel/ControlPanel.vue` suppliers that must relay the new
prop, so the real change is **7 files, +12/−1** (`diffs/proactive-check-plumbing.diff`, generated
against the live files).

**F-5 · Net-LOC is materially positive: +413 raw / +334 code-only, against a spec estimate of
+26 ±50.** Breakdown: `GameControlPanel` +113 · `TeacherPen` +261 · `PencilObject` +168 ·
`AssistSettings` −92 · `PencilModeToggle` −48 · plumbing +11. And that is *after* a −155-line
simplification the spec did not book (§5, deviation T′). Two real drawn objects and three wells of
markup are not free; F2 must be argued on rank and state-visibility alone, never on subtraction.

**F-6 · On mobile the paired wells do not share a row height** — the PENCILS well is 69px, the
TEACHER'S well 141px, and the grid is `align-items: start`, so the left column ends in dead space
with mismatched bottom edges (`out/f2-mobile-light.png`). One declaration (`align-items: stretch`)
fixes the edges; whether the pencils should *fill* is a design call for CRITIQUE.

**F-7 · The empty-slot pose (`off`) is the weakest of the four.** Two graphite straps plus a
dashed absence read as a bracket before they read as "the pen is put away" (`out/pen-pose-1-slot.png`).
It survives on the scribble-underlined `away` caption. If CRITIQUE wants it stronger, the cheapest
move inside the family is a faint stowed-pen silhouette inside the loop — which contradicts D4's
"deliberate absence," so it is a decision, not a patch.

## 5. DEVIATIONS FROM THE SPEC (declared)

- **D7′ — no `drawerPhase` prop plumbing.** `useControlsDrawer()` is a pure accessor over
  module-level state (verified: `drawerPhase` is a module-scope `ref`, the export function has no
  side effects). `GameControlPanel` reads it directly. D7's mechanism is unchanged —
  `createSequenceSubscription`, keyed to `drawerPhase === "opening"`, rail-instance-only via
  `!props.mobile`. **GameScene.vue is untouched** (spec booked +2) and the five games gain nothing
  for it. Strictly less blast radius.
- **T′ — the two template branches collapse into one.** The shipped file carries a full mobile
  tree and a full desktop tree; `mobile` now drives the grid class, `OptionSelector :mobile`, the
  hover-washi presence, and the legend. Three wells × two branches would have been two trays,
  which contradicts D8's "the same tray grammar compresses." Worth ≈−155 lines against the
  alternative. It does widen the diff surface (+550/−437) — a golden-risk item for CRITIQUE.
- **D1′ — the New-game group's accessible name is `aria-label="New game"`**, not
  `aria-labelledby`: the eyebrow `<h2>` it referenced is D3's first donor, and the washi tag is a
  `<span>` with no id. `useId` is dropped from the file (−2, one id-collision hazard retired).
- **D4′ — the "current zone" mark is `scribbleUnderline()`**, imported from
  `OptionSelector/scribbleUnderline.ts` (games→pencil, allowed). Reused, not re-invented.
- **The washi self-label is pinned by four declarations in the panel** (`top/left/transform/opacity`
  on `.tray-well :deep(.washi-label)`) rather than by a new `SheetWashiLabel` prop — same UI-9 move
  the peek chip already makes on the divider. Component untouched.
