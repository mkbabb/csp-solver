A1  scroll-padding-bottom on the scrollport             scene.css:151
    `.controls-card { scroll-padding-bottom: var(--action-bar-h, 0px) }`, declared on the
    unscoped rule — it is inert wherever the card doesn't scroll, so the `<1024` landscape
    card (in flow, a ratified rung) spends nothing.
    THE VALUE IS MEASURED, NOT SPELLED (GameControlPanel.vue:475-486): a `useResizeObserver`
    on `.action-bar` publishes `--action-bar-h` onto the card from
      the bar's BORDER box (`getBoundingClientRect`, never `contentRect` — the bar carries
      `padding-block`, and a content-box read is exactly what went stale on T6.2's deleted
      `--fold-bottom`)
      + the card's own `padding-bottom` (`bottom: 0` pins the stuck bar to the scrollport's
      PADDING edge, so that gap is part of the band the bar owns).
    At head that is 65 + 20 → 86px (ceil). Republished whenever the bar's box changes.

A2  the covered ribbon goes inert                       GameControlPanel.vue:503, :1044
    `:inert="ribbonCovered || undefined"` on `.play-controls` — the estate's own idiom,
    borrowed verbatim from `GameCard.vue:245`'s `:inert="!isActive || undefined"`.
    `ribbonCovered = portraitDock && !drawerInert`: the drawer's OWN parked flag, not
    `drawerOpen`, because the sheet covers the ribbon through the opening and closing glides
    too. Dock-only — in the row regime these four verbs sit inside the card the drawer
    carries, where an inert row would be a coarse iPad's undo button, deleted.

A3  the roster announces                                GameControlPanel.vue:876-881
    `role="log"` + `aria-live="polite"` + `aria-label="who's on this board"` on the `<ul>`.
    THE ANNOUNCING NODE IS THE ROSTER, and that is the answer to the `players-status`
    replacement defect: the one polite region at head is `v-if="!session.live.value"` and
    leaves the DOM the moment the room comes up. The roster is the node that actually
    mutates and the node that lives exactly as long as the room does, so it is the node that
    speaks. Its label is its own — the well is already named "players", and a reader hearing
    that twice learns nothing the second time.

A4  the roster is reachable                             GameControlPanel.vue:880
    `tabindex="0"` on the scrollport, pairing with A3's `role="log"`.

Q-4 the well is described                               GameControlPanel.vue:820, :827
    `aria-describedby` on the players well → the zone hint's own id. One string, still the
    same tape: the tag NAMES the compartment ("players"), the hint says what sharing it does
    ("share this board and everyone writes on the same grid"). A directly-referenced node is
    read whatever its hidden state (accname §4.1 step 2A), so the tape stays the decorative
    tape it is and no second literal is minted.
