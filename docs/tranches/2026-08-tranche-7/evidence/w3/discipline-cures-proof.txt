§2 — WHAT EACH ARM PROVES
────────────────────────────────────────────────────────────────────────────────────────────
a11y — instance 8. THE CONDITION: a genuinely silent guard. Every live region loses its
`role`/`aria-live` (so `guardAnnounced` is false) and the second Enter is answered with neither
a hold nor a switch — the ribbon simply vanishes. Page-side, no source touched.

  ARM 1 · the OLD form (2000ms sleep → one-shot `userEntries` → non-retrying implication)
          PASSED. This is the disease, exhibited: the guard was never heard, the ribbon never
          held, nothing settled — and because the count happened to read unchanged when the
          timer went off, the row certified the silence as compliance. No fixed duration fixes
          this; a longer sleep only moves the sample.
  ARM 2 · the CURED form REDS, and reds with the state it kept seeing:
            in flight {"enterSeen":1,"ribbon":false,"game":"sudoku","outgoing":81,"entries":1}
          Every field is load-bearing. `enterSeen:1` — the app DID receive the key, so this is
          not a lost keystroke. `ribbon:false` — it did not hold. `game:"sudoku"` with
          `outgoing:81` — it did not switch either. The disjunction has no arm to resolve on,
          so the poll exhausts and says so, where the sleep said nothing.

drawer — instance 10. THE CONDITION: the read lands MID-GLIDE. Nothing is mutated at all — the
fixed 900ms window is simply absent, which is exactly what a loaded runner does to it.

  ARM 1 · the OLD form (one-shot `boardBox`) REDS: |cx − 720| = 80.63px against a ≤2px band.
          The row's green was never earned by the assertion; it was bought by the 900ms window
          landing after a 520ms glide, on this machine, this time.
  ARM 2 · the CURED form (two consecutive frames must agree, verdict retried) GREENS from the
          same mid-glide instant — it waits for the board rather than for the clock.
  ARM 3 · ABLATION, the direct control: keep the frame, drop the agreement — read ONE frame of
          `twoFrameBoardBox` and assert it one-shot. REDS at |cx − 720| = 70.01px. So the
          consecutive-frame agreement is what earns ARM 2's green; the helper's shape does not.

Read together the two directions close the row: without the settle the assertion passes on a
lie (a11y ARM 1) or fails on the truth (drawer ARM 1/3), and with it the assertion means what
it says in both files.

// ═══ TEMPORARY — T7-W3 CH-63 instance 8 born-RED harness ════════════════════
// Env-gated so a sibling wave's run never sees it. Deleted after the bank.
test.describe('CH-63 proof', () => {
  test.skip(!process.env.CH63_PROOF, 'proof harness — set CH63_PROOF=1');
  test.describe.configure({ mode: 'serial' });

  /** THE MUTATION: a genuinely silent guard. It speaks to nothing (every live region loses its
   *  role/aria-live) and it answers the second Enter with neither a hold nor a switch — the
   *  ribbon simply vanishes. Page-side only; no source is touched. */
  async function silentGuard(page: Page) {
    await page.evaluate(() => {
      for (const r of document.querySelectorAll('[aria-live],[role="status"],[role="alert"]')) {
        r.removeAttribute('aria-live');
        r.removeAttribute('role');
      }
      window.addEventListener(
        'keydown',
        (e) => {
          if (e.key !== 'Enter') return;
          e.stopImmediatePropagation();
          e.preventDefault();
          document.querySelector('.gallery-guard')?.remove();
        },
        true,
      );
    });
  }

  test('ARM 1 — the OLD form (2000ms sleep, one-shot count) GREENS on it', async ({ page }) => {
    await armGuard(page);
    const before = await userEntries(page);
    const announced = await guardAnnounced(page);
    await silentGuard(page);
    await page.keyboard.press('Enter');
    await page.waitForTimeout(2000);
    const after = await userEntries(page);
    expect(
      announced || after === before,
      `announced=${announced} before=${before} after=${after}`,
    ).toBe(true);
  });

  test('ARM 2 — the CURED form REDS on it', async ({ page }) => {
    await armGuard(page);
    const before = await userEntries(page);
    const announced = await guardAnnounced(page);
    await page.evaluate(() => {
      const w = window as unknown as { __enterSeen: number };
      w.__enterSeen = 0;
      window.addEventListener('keydown', (e) => e.key === 'Enter' && w.__enterSeen++, true);
    });
    await silentGuard(page);
    await page.keyboard.press('Enter');
    let seen = await enterVerdict(page);
    await expect
      .poll(
        async () => {
          seen = await enterVerdict(page);
          return settleName(seen);
        },
        { timeout: 8000, message: 'the second Enter must settle into HELD or SWAPPED' },
      )
      .toMatch(/^(held|swapped)$/);
    const after = seen.entries;
    expect(announced || after === before, `announced=${announced} ${settleName(seen)}`).toBe(true);
  });
});
