exists to REPRODUCE THE CLASS, not merely to be red.

THE CURE, as a comparison rather than new data (the per-rep row counts were already
printed beside the term):

    const CLASS_MIN_ROWS = 2;
    const bCounted = B.filter((r) => (r.reds ?? 0) >= CLASS_MIN_ROWS);
    const bThin    = B.filter((r) => (r.reds ?? 0) > 0 && (r.reds ?? 0) < CLASS_MIN_ROWS);
