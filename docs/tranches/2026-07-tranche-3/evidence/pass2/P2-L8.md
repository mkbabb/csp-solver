### 2.1 Finalized partial shape — theme / utilities / print (Design B)

`src/assets/index.css` becomes a **5-line `@import` manifest** (drop-in captured at
`pass2/p6-accepted/partials/index.css`):

```css
@import 'tailwindcss';
@import './typography.css';
@import './css/theme.css';       /* @custom-variant, @font-face×3, @layer base{body}, @theme, .dark, @layer base{*,body} */
@import './css/utilities.css';   /* @layer utilities{…} verbatim — BOTH C1/C2 rules + interleaved animations */
@import './css/print.css';       /* @media (pointer:coarse) + @media print */
```

Partials captured at `pass2/p6-accepted/partials/css/{theme,utilities,print}.css`
(216 / 160 / 73 lines). **Two shape corrections vs the charter sketch, both mandatory:**

1. **`@font-face` moves into `theme.css`, NOT "stays in index.css."** CSS requires `@import` to
   precede all rules except `@charset`/`@layer` statements — `@font-face` then `@import` is invalid.
   So index.css is a **pure `@import` manifest**.
2. **NO separate contiguous `animations.css`.** The animation rules (`@keyframes shake`/`cell-reveal`,
   `.cell-reveal-animated`, the reduced-motion `*` block) are **interleaved** inside `@layer
   utilities` between non-animation rules (`.sheet-laminate` → `.solve-*` → animations →
   `.sudoku-cell:focus-within` → `.fira-code` → reduced-motion). Pulling them contiguous reorders the
   merged utilities layer and forfeits byte-identity. The utilities layer stays **one** partial.

The split is along **layer/at-rule boundaries** (theme-vars / utilities / print), not semantic concern.

### 2.2 The `../fonts/` rebase — LOAD-BEARING, documented, proven in BOTH modes

Tailwind v4 rebases `url()` relative to the **importing file**. `theme.css` sits at
`src/assets/css/`, so its `@font-face` must spell `url('../fonts/…woff2')` to land back at the
entry-relative `./fonts/`. Get it wrong and the build stays green while every font 404s at runtime.

- **Prod (build):** proven by byte-identity — `afterB2` re-emits the hashed
  `url(/assets/fraunces-subset-Cx5I8plf.woff2)` assets; the pre-fix `afterB` emitted
  `url(./css/fonts/fraunces-subset.woff2)` literals (sha `42c6c83f`, a silent 404).
- **Dev (watch) — NEW proof this pass** (the prototype tested prod byte-identity + dev
  `getComputedStyle` but did not fetch a font in dev): the dev server serves theme.css's `../fonts/`
  as `url('/src/assets/fonts/fraunces-subset.woff2')`, and `curl` of that path returns **HTTP 200**.
  The rebase resolves live in dev, not only in the hashed prod bundle.

`data:` URI textures (`--paper-clean-texture`, both theme arms) are **not** rebased — no change.
No other `url()` crosses a partition.
