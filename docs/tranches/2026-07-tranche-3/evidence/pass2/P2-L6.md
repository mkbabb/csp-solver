### Depth-lint calibration + negative control
Rule glob: `group: ['@pencil/*/*/*', '@pencil/*/*/*/**']`, scoped to `src/games/**` + `src/App.vue`/`src/main.ts`. Forbids 3+-level pencil imports; leaves 1-level (`@pencil/chrome/BoilDivider.vue`, `@pencil/config/pencilConfig`, `@pencil/types`) untouched. Proven to **bite** — reintroducing `import HandDrawnGrid from '@pencil/grid/HandDrawnGrid/HandDrawnGrid.vue'` in SudokuBoard yields:

and passes once restored. The two existing boundaries (pencil↛games, sudoku↮futoshiki) were preserved by **appending** the depth pattern into each game rule's `patterns` array (eslint flat config overrides same-named rules rather than merging — a naive second config block would have silently dropped the cross-game boundary; flagged for the wave).

### P4 pixel-bounding method — refined and definitive
Pinned deterministic boards via constructed `?board=` permalinks (auto-randomize otherwise differs per load); sudoku + futoshiki × light + dark @ 1280×800.

- **Animated capture (P4's method) is a weak bound.** Single same-code control AE ranged 0–1109 px; before-vs-after ranged 0–4107 px — futoshiki-light's before-vs-after (4107) *exceeded* its single control sample (1109). Boil stroke-jitter is stochastic; one control pair underestimates the jitter ceiling. This is a real limitation of P4's single-control bound.
- **Reduced-motion capture is definitive.** With `reducedMotion: 'reduce'`, boil freezes → renders deterministic. Same-code control AE = **0** on all four; **before-vs-after AE = 0 on all four**. Zero-pixel visual regression, proven — the entire animated delta was jitter.

**Recommendation for W-E/W-F authoring:** bound visual parity via `reducedMotion` determinism (control AE=0 ⇒ before-vs-after AE=0), not P4's single animated control.

## Shape findings for the wave (the prototype's job)

1. **Barrel granularity — subdir, not root.** Synthesis §1.5.6 names a *root* `pencil/index.ts`. A root barrel is **bundle-risky**: the lazy `AnswerKeyLaminate` rides a dynamic `import('@pencil/sheet/AnswerKeyLaminate.vue')` (2-level, exempt) and FutoshikiGame's static laminate import — routing those through a root barrel would defeat the on-first-peek lazy chunk. I built **subdir barrels** (`@pencil/chrome`, `@pencil/grid`) and proved chunk-shape parity holds. Recommend subdir barrels as the shape; a root `index.ts` re-exporting them is optional ergonomics, never the depth-lint mechanism.
2. **"11 deep sites" is a re-measure (K-series).** Only **6** external sites are 3-level-deep (App.vue ×2, both ControlPanels' OptionSelector, both Boards' HandDrawnGrid); the moved icons add 2 more that the barrel absorbs. R8's "11" counted internal-to-pencil deep imports too (e.g. HandwrittenLogo→OptionSelector/scribbleUnderline), which the external-scoped rule correctly leaves alone.
3. **Shared-home (Q7 / P2-L5 territory).** I placed the two composables in `src/composables/` (beside the existing `useTheme.ts`) and the pure codec in `src/lib/`. This is P2-L5's decision to ratify (`src/composables/` vs `src/games/shared/`); my prototype used the existing-home-consistent choice. `celebration.ts`-is-pencil-domain (Q7) is untouched here.
4. **`usePencilMarks` API shape.** The sole per-game variance is the propagate wire (sudoku `(values, size)` vs futoshiki `(values, boardSize, inequalities)`) — injected as a `propagate: () => Promise<Uint32Array>` thunk closing over each game's live state. `marksActive` is returned so each game keeps its identical `watch([values, boardGeneration], () => { if (marksActive.value) refreshMarks() }, {deep:true})` **byte-preserved**; the guard was NOT moved inside the composable (that would alter the timer-set behavior). `useUndoHistory` takes `applyValue` as an arrow wrapper (hoisting-safe).
5. **Not in this charter's row list, left untouched:** chrome loose-widget `widgets/` grouping (R5 L3 optional), `pencil/README.md` (D7), `pencil/types.ts` rehome (D6), glyph-dir consistency (L4). The `index.css` partial split is P6/P2-L8's row, not P2-L6.
