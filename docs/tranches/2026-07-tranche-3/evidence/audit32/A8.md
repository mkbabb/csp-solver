### 2. Sparse wrapped form — HOLDS

`csp-solver/src/puzzles/sudoku/generate.rs:65-106` (`parse_puzzle_field`) parses
the schema `{"puzzle":{"<pos>":<digit>,...}}` — confirmed byte-for-byte against
a live template:

```
$ cat csp-solver/data/sudoku_puzzles/4/easy/template-0.json
{"puzzle":{"1":13,"2":10,"4":14,...}}
```

Sparse (omitted cells implicitly 0, zero-filled at `generate.rs:88`), no
`solution`/`backtracks` fields (dropped per the doc comment at `generate.rs:71-72`).
The wrapped `{"puzzle":{...}}` envelope (not a bare `{...}`) is load-bearing per
the W4 wave doc: three independent readers depend on the `"puzzle"` key —
`parse_puzzle_field` (Rust embed), the Vite plugin's `data.puzzle` destructure
(`vite.config.ts:61-65`), and `gac_ab_corpus::parse_int_map` (which panics on a
missing `"puzzle"` key, confirmed at `examples/gac_ab_corpus.rs:137`).
