## The change — one file, size-derived bucket

**`web/frontend/src/pencil/sheet/AnswerKeyLaminate.vue`** (the ONLY repo file touched):

- The 40ms bucket constant in the noise-stagger delay becomes `keyBucketMs`, a computed
  derived from the key's own path count: mean mid-flight strokes
  ≈ N·dur/((buckets−1)·W + dur) capped at `KEY_CONCURRENCY_BUDGET = 48`, i.e.
  `W = max(40, ceil(180·(N−48)/(6·48)))` — floored at the shipped 40ms.
- Everything else keeps verbatim: the `(pos·31) % 7` Fisher-Yates-echo noise ordering, the
  7 buckets, the **180ms per-glyph duration** (now via `KEY_DRAW_MS`), the **80ms lead**
  (`KEY_DELAY_LEAD_MS` — the lay-down still lands first; widening it would only delay the
  first stroke, not cut concurrency, so it stays), lay/lift transitions, opacity 0.9.
- Scale map: 9×9 (46 translucent / 81 opaque paths) → **40ms, window 80–320ms
  byte-identical to shipped**; 16×16 opaque (256) → **130ms, window 80–860ms**, ≤ two
  buckets ≈ 2N/7 ≈ 73 strokes ever concurrent. Continuous in N (25×25 scales too) — a
  size-derived calc, no JS branch.
- **`index.css` primitive UNTOUCHED** — loudly: `--draw-delay` was already the consumer
  knob; the primitive needed no new knob. No other surface's stagger changes.
