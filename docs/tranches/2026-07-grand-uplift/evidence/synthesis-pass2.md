## 5. Critique targets for Pass 3

Adversarial hardening list — claim / strongest attack / what refutes the attack.

**T1 — "The kernel is behavior-preserving."** Attack: parity rests on 9 sudoku combos + one 2 s criterion pair; queens/map-coloring/futoshiki/COP enumeration paths and `fc_chrono` were never A/B'd; the −12.1% could be shared-host noise; and the retained `backjumping` no-op means three tests now pass vacuously. Refutes: full criterion suite (queens_all, map_coloring, lattice, assignment) on quiet hardware + delete the field and re-assert; an enumeration-count test corpus run pre/post.

**T2 — "GAC default-ON in AllDifferent."** Attack: 9×9 evidence is n=1 fresh boards and the first draft's board showed GAC-on ~2× *slower*; the shipped 9×9 path is the product's hot path; 150,814 gac_calls at 16×16 hints at real constant cost that MRV-easy boards pay for nothing. Refutes: A/B the 5-puzzle hard corpus + template banks (N=2..4) under the exact py.rs production config, GAC on/off, ≥30 boards; keep ON only if 9×9 stays within noise; otherwise gate by N.

**T3 — "AcFc→Ac3 in AssignmentBuilder is safe for morph."** Attack: morph-lazy-cost's bit-identical-selection and 7.6–13.4× numbers were measured with the *old* builder config in a different worktree; changing the builder's pruning changes Tier-2's search shape and could interact with the lazy cheap-score matrix (different node counts, different tie exploration). Refutes: joint A/B on the morph corpus with both changes composed — selection vectors still identical, n=6 solver-bound case improves or holds.

**T4 — "nld-nogoods are sound and restarts are correct."** Attack: zero tests exercise `restarts:true` or `Ordering::Chs`; the soundness argument leans on givens-invariance + baked baseline — a future `solve()` (no givens) restart path, or interaction with the kernel's trail/`undo_to(0)`, could invalidate it silently. Refutes: enumerate-all-vs-brute-force under restarts on satisfiable+unsat instances; a property test asserting no solution is ever pruned by a recorded nogood; port to the kernel *with* those tests, not before.

**T5 — "The six Rust worktrees compose."** Attack: four prototypes evolved `ac3_from_variable`/`forward_check` signatures divergently (trail param / blame return / worklist param / `'static` bounds); kernel deleted files two others patched; nobody has built the composed tree — the 139/139 evidence is per-worktree, not joint. **T6 — "GIL liberation is proven."** Attack: 71–77% heartbeat (not ~100%) is unexplained — residual GIL-held marshaling or just host load?; the Pass-1 metric "4 concurrent solves don't freeze /health" and the Docker multi-stage wheel build were never re-run; board.py still doesn't wire the token, so the shipped service is exactly as frozen as before until that lands.
